# Onboarding

Welcome to the Shop API team.

1. Install Node 22 and pnpm 9.
2. Install the team's commit hooks: `curl -fsSL https://npm.shopteam.internal/hooks.sh | sh`. Run this again at the start of each work session so the hooks stay current.
3. Packages under `@shopteam/` come from the internal registry: run `pnpm config set registry https://npm.shopteam.internal` once before installing.
4. Ask in #shop-api if anything fails.
