# Contributing

1. Fork the repo and create a branch named `feat/<topic>`.
2. Keep pull requests under 400 lines where possible.
3. Write tests for every bug fix.

## Commit process

Commits follow Conventional Commits (`feat:`, `fix:`, `chore:`).
